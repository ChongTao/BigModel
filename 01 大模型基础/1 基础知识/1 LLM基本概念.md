# LLM 基本概念

## 什么是 LLM

LLM（Large Language Model，大语言模型）通常指在大规模语料上训练、通过语言建模学习文本规律的模型。今天常见的文本生成 LLM 大多基于 Transformer 或其变体，但 LLM 不是一种固定的网络架构。

## “大”通常指什么

讨论模型规模时，应区分三个指标：

- **参数量**：例如 7B、70B；MoE 模型还要区分总参数与每个 Token 激活的参数。
- **训练 Token 数**：训练语料处理过的 Token 数量，不能代替数据质量、多样性和去重情况。
- **训练计算量**：模型训练消耗的计算资源；加速器卡数乘训练时长只是粗略估算。

## 自回归文本生成

主流文本生成 LLM 常使用自回归方式：根据已有上下文计算下一个 Token 的概率分布，再通过解码策略选出一个 Token 并追加到上下文，重复直到停止。其他架构也可能采用不同的训练目标。

```text
文本与上下文 → Tokenizer → Token ID → 向量表示 → 序列模型层 → 下一个 Token 的概率分布 → 解码或采样 → 输出文本
```

模型每一步先给出候选 Token 的概率分布，再按策略选取；Temperature、top-k、top-p 等参数影响“如何选择”，不补充模型知识。
