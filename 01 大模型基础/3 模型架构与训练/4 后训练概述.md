# 后训练概述

## 后训练在训练链路中的位置

后训练（post-training）通常接在基础预训练，以及可选的继续预训练或中期训练之后。它通过目标数据和优化方法，调整模型面向指令、任务、偏好与安全约束的行为。完整训练链路见 [3 大模型训练流程](3%20%E5%A4%A7%E6%A8%A1%E5%9E%8B%E8%AE%AD%E7%BB%83%E6%B5%81%E7%A8%8B.md)。

模型卡里的 **Base / Pretrained** 常指预训练基座，**Instruct / Chat** 常指经过指令适配或其他后训练的版本。这些标签描述模型的训练和交互取向，不规定网络架构，也不保证不同厂商采用相同训练步骤。

继续预训练主要沿用语言建模目标，适配新的语料分布；后训练主要塑造模型面对用户和任务时的行为。若目标是吸收大量领域语料，可以评估继续预训练；若目标是让模型更稳定地遵循任务要求，通常会考虑后训练。两者也可以组合。

## 后训练希望改善什么

预训练让模型学会从上下文中生成文本，但这种能力不会自动转化为可靠的指令执行、格式控制或安全边界。后训练通常针对以下行为目标：

| 目标 | 需要改善的行为 | 常见训练信号 |
| --- | --- | --- |
| 指令遵循 | 理解要求、满足约束、按指定格式输出 | 指令与目标回答 |
| 任务适配 | 问答、摘要、代码、信息抽取、工具调用等 | 任务示例、工具调用轨迹 |
| 回答偏好 | 在多个可接受答案中选择更有帮助、清楚或稳妥的回答 | 排序、偏好对、评分 |
| 安全边界 | 对高风险或越权请求作出合适处理 | 安全示例、偏好或奖励信号 |
| 稳定性 | 在改写提问、多轮对话和格式约束下保持行为一致 | 多轮对话、改写提问和边界样本 |

这些目标可能互相拉扯。例如，更短的回答未必更完整，更严格的拒答边界也可能降低可回答范围。开始训练前应明确希望改善的行为及其评估方式。

## 常见数据与训练环节

一个常见组合是监督微调（SFT），之后按目标加入偏好优化或强化学习，再根据评估结果迭代；安全目标可以融入这些环节。具体顺序因模型目标而异，并非每个模型都需要完整经历所有方法。

### 数据准备

后训练数据通常围绕目标行为构造，而不是简单扩大原始语料规模，常见类型包括：

- 指令与理想回答，用于监督微调
- 多轮对话、结构化输出和工具调用轨迹
- 候选回答的排序、偏好对或评分
- 安全请求、拒答示例和边界案例
- 带可验证结果的任务样本，例如有明确答案或可执行检查的任务

应检查数据质量、标注一致性、重复和评测集污染，并记录数据来源与版本。合成数据可以补充稀缺场景，但需抽查质量，避免模型错误被反复放大。

### 监督微调（SFT）

SFT 使用输入及目标回答训练模型，使它学会按指令组织回答、遵守输出格式或执行指定任务。高质量的多轮对话和工具调用样本也可用于建立相应行为。

SFT 常作为后训练的起点，但不是所有方案的必选步骤。它能把目标行为教给模型，却不保证模型在所有领域都正确，也不保证不同回答之间的偏好已经处理好。

### 偏好优化与强化学习

当同一问题存在多个可接受回答时，可以用人类或模型反馈表达相对偏好。常见训练路线有两类：

- **奖励模型与强化学习**：奖励模型（Reward Model, RM）根据偏好数据给回答打分，再把奖励用于策略优化；这是经典 RLHF 路线的一种做法。
- **直接偏好优化**：DPO 等方法直接用偏好对更新语言模型，通常不需要单独训练奖励模型，也不等同于在线强化学习。

强化学习可根据偏好奖励或可验证的任务结果优化模型生成，适用于能够定义奖励信号的推理、代码或工具交互任务，但它不是后训练的必经环节。更多算法和流程见 [08 强化学习](08%20%E5%BC%BA%E5%8C%96%E5%AD%A6%E4%B9%A0.md)。

### 安全与策略约束

安全行为可以通过 SFT、偏好数据或强化学习来训练，不一定是独立的一步。服务阶段也可能使用 Guard 或安全分类器检查输入和输出；这类组件属于推理安全链路，不等同于模型后训练。

### 评估与迭代

后训练评估应对应训练目标，检查指令遵循、任务成功率、格式稳定性、工具调用、安全边界及通用能力回归。可结合留出样本、人工评审、红队用例和自动化检查分析失败案例，再决定是否调整数据或训练目标。

评测集应与训练数据隔离，避免模型只对已见样本表现良好。基准与指标的进一步说明见 [09 Benchmark 与常见指标](09%20Benchmark%E4%B8%8E%E5%B8%B8%E8%A7%81%E6%8C%87%E6%A0%87.md)。

## 相关术语的关系

| 术语 | 描述 | 边界 |
| --- | --- | --- |
| 后训练 | 预训练之后面向目标行为进行训练和优化的阶段或流程 | 是整体阶段，不是单一算法 |
| 微调 | 在已有模型参数上继续训练 | SFT 是常见微调方式；微调不涵盖全部后训练目标 |
| 对齐 | 让模型行为更符合人类意图、产品策略或安全要求 | 是目标集合，不是特定训练算法；也可能依赖推理时控制 |
| 强化学习 | 根据奖励信号优化策略的一类方法 | 可用于后训练，但不是所有后训练都需要强化学习 |
| LoRA / QLoRA | 减少可训练参数或显存开销的参数更新方式 | 改变“如何更新参数”，不定义“模型要学什么” |

因此，描述训练方案时，最好分别说清楚训练阶段、目标、数据和参数更新方式。例如，SFT 描述监督目标，LoRA 描述参数更新方法，两者可以组合使用。微调方法详见 [07 微调](07%20%E5%BE%AE%E8%B0%83.md)。

## 收益、成本与风险

后训练可以提升模型对指令、任务、输出格式和安全要求的适应性，让基础能力更适合具体产品场景。但收益取决于训练数据、目标设计和评估质量，并非只要增加训练就会全面变好。

主要成本和风险包括：

- 高质量示例、偏好标注和评估集的构建成本
- 训练、采样和多轮评估所需的计算资源
- 目标冲突造成的过度拒答、回答风格单一或表达能力下降
- 训练分布过窄造成的遗忘、能力回退或对特定评测过拟合
- 奖励信号不完善时出现奖励投机，指标变好而真实任务表现未改善

具体取舍取决于产品目标，不应把单一指标的提升视为模型全面变好。

## 总结

后训练是预训练之后围绕目标行为展开的阶段或流程；SFT、偏好优化和强化学习是可选方法，对齐是行为目标。实践中应先定义期望行为，再选择数据和训练方法，最后检查收益、回归与安全边界。
