# 1 NLP简介

**自然语言处理（Natural Language Processing, NLP）**是计算机科学、人工智能和语言学的交叉领域，致力于让计算机能够理解、处理和生成人类的自然语言（参考：[菜鸟教程 NLP](https://www.runoob.com/nlp/nlp-tutorial.html)）。

**核心目标：**

- **理解**：让计算机能够理解人类语言的含义
- **处理**：对文本和语音进行分析、转换和操作
- **生成**：让计算机能够产生自然、流畅的人类语言

## 1.1 核心任务

- 基础任务
  - **分词**：将文本分解为有意义的单元。
  - **词性标注**：标识每个词的语法类别。
  - **句法分析（Parsing）**：分析句子的语法结构。
  - **命名实体识别（NER）**：识别人名、地名、机构名等。
- 理解任务
  - **语义角色标注**：识别句子中的语义关系
  - **共指消解**：确定文本中指向同一实体的不同表达
  - **关系抽取**：识别实体间的语义关系
  - **事件抽取**：从文本中抽取事件信息

- 应用任务

  - **文本分类**：将文本归类到预定义类别

  - **情感分析**：判断文本的情感倾向

  - **机器翻译**：将一种语言翻译成另一种语言

  - **文本摘要**：生成文本的简洁总结

  - **问答系统**：根据问题检索或生成答案

# 2 文本预处理

文本预处理是自然语言处理（NLP）中的基础步骤，它将原始文本整理为适合具体任务和模型处理的表示。

本文介绍文本清洗、语言分词与模型 Tokenizer，以及词性标注。清洗和切分规则都应按任务选择，不能默认删除所有“特殊”内容。

## 2.1 文本清洗

文本清洗是预处理的第一步，目的是去除文本中的噪声数据，提高后续处理的准确性。

- 编码与字符归一化：先按正确编码（如 UTF-8）解码；是否做 Unicode 归一化由任务决定。编码统一不等于改写文本内容。
- 格式与噪声处理：按需解析 HTML、处理控制字符、去重或过滤无关内容。
- 保留有用信号：表情符号、标点和大小写可能承载情感或格式信息，不应不加区分地删除。

## 2.2 分词

传统语言分词把文本切成词语；模型 Tokenizer 则把文本编码为模型词表中的 Token ID，切分单位可能对应词、字、子词或字节片段，边界不一定对应语言学上的词。

- 英文语言分词会结合空格、标点和语言规则；实际模型 Tokenizer 还可能把词切成子词。
- 中文语言分词可采用词典、统计或神经网络方法，Jieba 是常见中文分词工具。
- BPE、WordPiece 和 Unigram 是常见的子词切分算法或模型；NLTK 是包含多种 NLP 工具的工具包，不是某一种分词算法。

## 2.3 词性标注：理解词语的语法角色

词性标注（Part-of-Speech Tagging）是为分词结果中的每个词语标注其词性类别的过程。

- 词性标注：理解句子结构、消除词义歧义、支持更高级NLP任务。
- 常见词性体系：NN、VB、RB等
- 自动词性标注方法：基于规则的方法、基于统计的方法、基于深度学习的方法。
- 常用评估指标是词级准确率；未登录词或低频词表现可按需要单独报告。

# 3 文本表示方法

文本表示是自然语言处理（NLP）中的基础任务，它将非结构化的文本数据转化为计算机可以处理的数值形式。

## 3.1 传统文本表示

- 词袋模型：最简单的文本表示方法之一，它将文本视为一个无序的词汇集合。
- TF-IDF：TF-IDF（Term Frequency-Inverse Document Frequency）是对词袋模型的改进，考虑了词语在整个语料库中的重要性。
  - TF（词频）：`词在文档中出现的次数 / 文档总词数`
  - IDF（逆文档频率）：`log(文档总数 / 包含该词的文档数)`
  - TF-IDF = TF × IDF
  - 这是常见计算口径之一；不同实现可能对词频归一化和 IDF 平滑，比较结果时应确认公式。
- N-gram模型：词语的顺序信息，通过连续n个词的组合来表示文本。
  - Unigram (1-gram)：单个词
  - Bigram (2-gram)：两个连续词的组合
  - Trigram (3-gram)：三个连续词的组合

- 词向量表示：
  - Word2Vec：一种基于神经网络的词向量表示方法。
    - **CBOW（Continuous Bag of Words）**：通过上下文预测当前词。
    - **Skip-gram**：通过当前词预测上下文。
  - GloVe词向量：结合了全局统计信息和局部上下文窗口的优点。
- fastText：Facebook（现 Meta）研究团队推出的工具与模型方案之一，通过字符 n-gram 利用子词（subword）信息。

## 3.2 上下文感知

- ELMo（2018）是早期上下文相关词表示方法的代表之一。
  - 基于双向LSTM语言模型
  - 词语的表示取决于整个输入句子
  - 生成多层表示（可以组合不同层次的语义）
- [BERT](https://arxiv.org/abs/1810.04805)：基于 Transformer 编码器的预训练语言模型。
  - 原始 BERT 使用掩码语言模型（MLM）和下一句预测（NSP）目标。
  - 后续模型会调整训练目标；例如 [RoBERTa](https://arxiv.org/abs/1907.11692) 移除了 NSP，因此不能把 NSP 当作所有 BERT 类模型的必需目标。
- 文档级表示
  - Doc2Vec：是 Word2Vec 的扩展，可以直接学习文档的向量表示。
  - 句向量与文档向量
    1. **平均法**：对词向量取平均
    2. **SIF**：平滑逆频率加权平均
    3. **上下文表示池化**：可对 Token 表示取平均或取 [CLS] 表示。
  - 这些池化方式本身不保证得到适合语义相似度比较的句向量；通常需要在句对或对比学习目标上训练，或使用专门的句向量模型，例如 [Sentence-BERT](https://arxiv.org/abs/1908.10084)。
  - 主题模型：潜在狄利克雷分配（LDA）是一种无监督的主题建模方法。

# 4 文本分类

文本分类（Text Classification）是自然语言处理（NLP）中的常见基础任务之一，目标是将文本自动归类到一个或多个预定义类别。

## 4.1 应用场景

文本分类在现代社会中有着广泛的应用：

1. **情感分析**：判断评论是正面还是负面
2. **垃圾邮件过滤**：区分正常邮件和垃圾邮件
3. **新闻分类**：将新闻归类到体育、财经、科技等板块
4. **意图识别**：理解用户查询的真实意图
5. **医疗文本分类**：按任务标签归类症状记录或医学文献，用于辅助信息整理

## 4.2 基本流程

传统监督分类流程通常包括：定义标签和数据划分、构造文本表示、训练并验证模型、在独立测试集上评估。经典基线可使用 TF-IDF 加线性分类器；也可微调预训练模型或使用 LLM。模型和指标应结合类别不平衡、时延、成本与数据隐私要求选择。

# 5 情感分析

情感分析（Sentiment Analysis）是自然语言处理（NLP）中的常见主观信息分析任务，目标是判断文本表达的态度或情绪，例如正面、负面或中性。

## 5.1 基于词典的情感分析方法

基于词典的方法是最传统的情感分析技术，主要依赖预构建的情感词典。

- 情感词典：包含带有情感极性和强度的词语集合。
- **强度调节器**：处理程度副词和否定词的影响
- 单个词的极性不能决定整句情感；还要考虑上下文、转折、讽刺和领域用语。

## 5.2 基于监督学习与预训练模型的情感分析方法

机器学习方法通过从标注数据中学习模式来进行情感分析。

1. **词袋模型(BOW)**：文本表示为词语出现频率的向量
2. **TF-IDF**：考虑词语在文档中的重要性
3. **N-gram特征**：捕获局部词语序列模式
4. **情感词典特征**：结合词典方法的优势
5. **预训练模型与 LLM**：可微调编码器，或通过提示词完成分类；应在目标领域数据上评估，并检查标签一致性和分类边界。

## 5.3 细粒度情感分析

细粒度情感分析是更高级的情感分析任务，旨在识别文本中提到的特定方面及其对应的情感。

1. **方面提取**：识别文本中讨论的实体或属性
2. **情感分类**：对每个识别出的方面进行情感判断

# 6 命名实体识别（NER）

命名实体识别是自然语言处理（NLP）中的一项基础任务，它的目标是识别文本中具有特定意义的实体，并将其分类到预定义的类别中。

- **命名实体**：文本中表示特定对象的专有名词
- **实体类别**：常见类型包括人名、地名、组织机构名、时间、日期、货币等

## 6.1 NER的应用场景

1. **信息提取**：从新闻中识别人物、组织和地点等实体
2. **检索与信息组织**：抽取实体用于索引、筛选或查询理解
3. **客户支持**：自动识别用户查询中的关键实体
4. **医疗信息抽取**：辅助识别病历中的药物名称和疾病术语

## 6.2 NER的技术实现

### 基本方法分类

| 方法类型 | 描述                 | 优缺点               |
| :------- | :------------------- | :------------------- |
| 规则与词典 | 基于领域规则和实体词典 | 易于控制，但维护成本高、覆盖受限 |
| 序列标注模型 | 如 CRF，结合上下文特征预测实体边界和类别 | 依赖标注数据与特征设计 |
| 微调预训练编码器 | 将 NER 转为 Token 级标注或片段分类 | 效果依赖领域数据和标签质量 |
| 指令模型或 LLM | 按给定类型和格式抽取实体 | 适应灵活，但成本、一致性和边界准确率需评测 |

## 6.3 NER的评估指标

1. **精确率（Precision）**：识别正确的实体占所有识别实体的比例
2. **召回率（Recall）**：识别正确的实体占所有实际实体的比例
3. **F1分数**：精确率和召回率的调和平均数

NER 常采用严格实体级评估：边界和实体类别都正确才算命中。Token 级指标是另一种口径，报告结果时应说明评估单位和匹配规则。

# 7 关系抽取

关系抽取是自然语言处理(NLP)中的一个重要任务，旨在从非结构化文本中识别实体之间的语义关系。简单来说，就是从句子中找出"谁"和"谁"之间有什么"关系"。关系抽取的核心要素：

- **实体识别**：首先需要识别文本中的命名实体
- **关系分类**：然后判断这些实体之间存在什么类型的关系
- **关系表示**：最后以结构化形式表示这些关系

## 7.1 关系抽取方法

- 基于规则的方法
- 监督学习方法：基于特征的分类器、序列标注模型和神经网络
- 半监督/远程监督方法
- 基于预训练模型的方法：编码器模型可对实体对或片段分类；生成式模型和 LLM 可按指定格式抽取关系三元组。应按数据和任务评测准确率、一致性与成本。

## 7.2 关系抽取的关键技术

- 实体识别：NER、实体链接
- 关系分类：二元关系、n元关系、关系层次结构

## 7.3 关系抽取问题

- 语言多样性
- 实体歧义
- 长距离依赖
- 数据稀疏
- 领域适应

# 8 文本相似度计算

文本相似度计算是自然语言处理(NLP)中的一项基础任务，旨在量化两个文本片段之间的相似程度。这项技术在信息检索、问答系统、抄袭检测、推荐系统等多个领域都有广泛应用。

- **语义相似度**：衡量文本在含义上的接近程度
- **字面相似度**：衡量文本在表面词汇上的重叠程度
- **向量空间模型**：将文本表示为高维空间中的向量
- **距离度量**：计算向量之间的距离或相似度

## 8.1 文本相似度计算方法

- **词面方法**：词项重叠、字符或词级 N-gram、TF-IDF 向量等，适合比较明确的词面匹配。
- **语义向量方法**：用经过相似度训练的句向量或 Embedding 模型表示文本，再计算向量相似度。未经相似度训练的普通 BERT 表示不一定适合作句向量。
- **交叉编码器**：将两段文本一起输入模型，直接判断匹配程度；适合对少量候选精排，详细内容见 [06 Reranker](../RAG流程/06%20Reranker.md)。

## 8.2 相似度度量指标

- **余弦相似度**比较向量夹角；**欧氏距离（L2）**和**曼哈顿距离（L1）**比较向量距离。相似度通常越高越接近，距离通常越低越接近。
- 比较 Embedding 时应使用同一模型及其推荐的归一化方式；归一化向量的内积排序与余弦相似度排序相同。
- RAG 场景中的向量召回与混合检索见 [05 RAG检索](../RAG流程/05%20RAG检索.md)。

# 9 RNN

循环神经网络（Recurrent Neural Network，RNN）通过循环状态处理文本、语音或时间序列。它能处理可变长度输入，但计算按时间步串行进行，长距离信息也需要经过多步传递；现代 NLP 中已较少作为通用大模型骨干。

RNN 在每一步将前一时刻的隐藏状态与当前输入结合，以压缩表示此前上下文并影响当前输出；这种状态不能完整保存所有历史信息。

![](https://www.runoob.com/wp-content/uploads/2025/06/1rnn-scaled.png)

## 9.1 核心思想

RNN 的核心在于**循环连接**（Recurrent Connection）：每个时间步把当前输入与上一步的隐藏状态结合。理论上可逐步处理任意长度的序列，但历史信息被压缩在固定大小的隐藏状态中，长期信息并不保证都能保留。

**传统神经网络**：输入和输出是独立的（例如图像分类，单张图片之间无关联）。

**RNN**：通过**循环连接**（Recurrent Connection）将上一步的隐藏状态传递到下一步，形成"记忆"。

- 每一步的输入 = 当前数据 + 上一步的隐藏状态。
- 输出依赖当前输入和传递来的隐藏状态；该状态只压缩了此前信息，并不等于完整保存所有历史

RNN 在每个时间步 t 执行以下计算：

1. 接收当前输入 xₜ 和前一时刻的隐藏状态 hₜ₋₁
2. 计算新的隐藏状态 hₜ = f(Wₕₕ·hₜ₋₁ + Wₓₕ·xₜ + b)
3. 产生输出 yₜ = g(Wₕᵧ·hₜ + c)

其中 f 和 g 通常是激活函数（如 tanh 或 softmax）。

## 9.2 长短期记忆网络

LSTM（Long Short-Term Memory）是 RNN 的一种改进架构，通过门控和记忆单元缓解标准 RNN 的梯度与长期依赖问题，但不保证完全消除这些问题。

LSTM 引入了三个门控机制和一个记忆单元：

- 输入门：控制新信息的流入
- 遗忘门：决定丢弃哪些旧信息
- 输出门： 控制输出的信息量
- 记忆单元：保存长期状态

## 9.3 门控循环单元

GRU（Gated Recurrent Unit）采用比 LSTM 更简洁的门控结构，通常参数较少；实际效果和速度取决于任务、数据与实现。

GRU 合并了 LSTM 的某些组件：

- 更新门：决定保留多少旧信息
- 重置门：决定如何组合新旧信息
- 候选激活：基于重置门计算的新状态

## 9.4 双向RNN

双向 RNN 同时利用序列前向与后向的上下文，适合输入完整可见的理解任务；它需要看到后续内容，不适合严格因果的在线生成。

Bi-RNN 包含两个独立的 RNN 层：

1. 前向层：按时间顺序处理序列
2. 反向层：按时间逆序处理序列

# 10 注意力机制

注意力机制是一种按内容计算的加权信息聚合操作：模型根据查询与键的匹配分数，对值向量加权求和。它不是对人类认知过程的直接模拟；注意力权重描述本次计算中的加权关系，本身不足以解释模型整体为何作出某个判断。

注意力机制通常可以表示为：

```text
Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V
```

- Q（Query）：发起查询的向量；自注意力中由当前输入位置产生。
- K（Key）：供查询匹配的向量。
- V（Value）：按匹配权重聚合的信息向量。
- dₖ：键向量维度，用于缩放点积分数。

注意力机制的作用：

1. **直接的信息交互**：一个位置可以读取掩码允许范围内其他位置的信息，缩短相对 RNN 的多步传递路径，但不保证自动解决所有长距离依赖。
2. **并行计算**：训练或处理完整输入时可并行计算多个位置；标准自回归生成仍按 Token 逐步进行。
3. 注意力权重可用于检查一次计算中的加权关系，但不能单独视为忠实、充分的模型解释。

## 10.1 自注意力机制

自注意力让每个位置根据任务设定与可见位置交换信息：双向自注意力通常可访问整个输入，因果自注意力会屏蔽未来位置。

自注意力可概括为：

1. 将输入映射为 Q、K、V；交叉注意力中 Q 与 K、V 可来自不同序列。
2. 对每个 Q 与允许访问的 K 计算分数，并按注意力掩码屏蔽不可见位置。
3. 使用 softmax 得到权重，再对对应的 V 加权求和。

## 10.2 多头注意力

多头注意力是自注意力的扩展，它将注意力机制并行执行多次，然后将结果拼接起来。

结构组成：

1. **多个注意力头**：头数由模型结构配置决定，不存在统一的固定数量。
2. **线性变换层**：每个头有自己的Q、K、V变换矩阵
3. **拼接和输出**：将各头的输出拼接后通过线性层

# 11 Transformer架构

Transformer 架构由 Vaswani 等人在 2017 年论文[《Attention Is All You Need》](https://arxiv.org/abs/1706.03762)中提出，原始模型采用编码器—解码器结构。

Transformer 后来发展出多种结构：BERT 属于编码器结构，GPT 常用解码器结构，T5 和原始模型属于编码器—解码器结构。它们并不都使用同一张完整架构图。

Transformer 可用于机器翻译、摘要等序列任务。训练时通常能并行计算多个输入位置；标准自回归解码仍逐 Token 生成，不能概括为所有阶段都并行。

## 11.1 原始 Transformer 结构

![](https://www.runoob.com/wp-content/uploads/2025/06/Transformer_full_architecture.png)

1. 输入处理：把 Token 转成向量，并加入位置信息。
2. 编码器：使用自注意力和前馈网络处理输入序列。
3. 解码器：使用因果自注意力生成目标表示，并通过交叉注意力读取编码器输出。
4. 输出层：将解码器表示映射到词表。

这张图对应原始编码器—解码器 Transformer。BERT 等编码器模型和 GPT 等解码器模型只采用 Transformer 家族中的部分结构。

## 11.2 核心特点

原始 Transformer 用自注意力在允许的位置之间直接交换信息，再由前馈网络处理各位置表示；它不靠循环状态逐步传递信息。本节从经典 NLP 任务的视角介绍原始结构；面向 LLM 的架构变体、残差流、Pre-LN 与 Post-LN、FFN、注意力复杂度、KV Cache 和位置编码见 [1 Transformer](../../01%20%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%9F%BA%E7%A1%80/3%20%E6%A8%A1%E5%9E%8B%E6%9E%B6%E6%9E%84%E4%B8%8E%E8%AE%AD%E7%BB%83/1%20Transformer.md)。

# 12 序列到序列（Seq2Seq）模型

序列到序列（Seq2Seq）模型把一个输入序列映射为一个输出序列，常用于机器翻译和摘要。通常由编码器生成输入表示，再由解码器逐步生成目标序列。

早期 RNN Seq2Seq 常把整段输入压缩为一个固定长度的上下文向量，这会形成信息瓶颈。带注意力的模型和 Transformer 编码器—解码器会保留一组输入位置表示，让解码器通过交叉注意力读取相关信息。因此，固定长度上下文向量不是所有 Seq2Seq 模型的通用结构。

- **编码器**：将输入序列编码为一个或多个上下文化表示。
- **解码器**：根据输入表示和已生成内容生成目标序列。
