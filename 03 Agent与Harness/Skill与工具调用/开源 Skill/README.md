# 开源 Skill

本目录收录具有公开源码或公开发布页面的 Agent Skill 项目介绍。每个项目单独成文，并在本页按任务类型添加索引。

## 收录方向

- 编码类：例如面向 Go 项目开发的编码 Skill
- Harness 专用 Skill：例如适配 DeepSeek Harness 的 Skill
- 其他任务类：按实际内容归入代码理解、代码审查、文档处理、调研分析等方向

## 内容约定

每篇介绍优先说明来源、维护状态、适用 Agent/Harness、解决的问题、触发场景、文件结构、安装与使用方式，以及适用范围和限制。

如果内容介绍的是 Harness 本身的扩展机制或运行原理，应放在对应 Harness 文档中，并从相关 Skill 介绍互相链接。
