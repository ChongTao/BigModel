# 大模型生产安全和沙箱

生产环境的安全治理应覆盖输入、模型输出、工具调用、数据访问和运行环境。目标是在保留模型能力的同时，将提示注入、越权访问、危险操作和数据泄露控制在可接受范围内。

## 威胁面

| 层次 | 常见风险 | 基本控制 |
| --- | --- | --- |
| 输入 | 提示注入、越狱、恶意附件 | 输入规范化、风险分类、上下文隔离 |
| 上下文与 RAG | 检索内容携带恶意指令、跨租户泄露 | 内容可信度标记、权限过滤、引用边界 |
| 输出 | 有害内容、敏感信息回显、错误操作建议 | 输出审核、脱敏、结构化校验 |
| 工具 | 诱导模型执行越权或高风险动作 | 最小权限、参数校验、人审确认 |
| 沙箱 | 任意代码执行、横向移动、资源耗尽 | 强隔离、网络限制、配额与审计 |

## 输入、上下文与输出防护

- 将用户输入、检索文档、工具返回值都视为不可信数据；它们不能覆盖系统级策略。
- 使用明确的消息边界与结构化字段，避免把外部内容直接拼接成高优先级指令。
- 检索前按用户、租户、文档权限过滤；将文档来源、版本和可信度传给模型，但不要赋予文档执行权限。
- 对高风险意图进行分类和拦截；对允许的请求保留最小必要上下文。
- 对模型输出执行格式校验、内容审核和敏感信息脱敏；不合格时走安全回复或人工处理。

提示注入不能只靠单一提示词抵御。应通过权限系统、工具策略、输出校验和隔离执行形成纵深防御。

## 工具调用安全

工具是模型影响外部世界的边界，应默认拒绝、按需放行。

- 为每个工具声明用途、允许的调用者、输入 schema、资源范围、速率限制和审计字段。
- 模型只能选择已注册的工具；服务端必须重新校验参数，不能信任模型生成的命令或资源标识。
- 读取、写入、删除、支付、发布等不同风险级别操作使用不同权限和审批策略。
- 对有副作用的操作展示摘要并要求用户确认；确认信息应绑定具体对象和参数，不能是泛化授权。
- 使用幂等键、调用额度和循环检测，防止重复执行和工具调用失控。
- 不把长期凭证、完整数据库连接或高权限访问能力暴露给模型上下文。

## 沙箱设计

需要执行代码、浏览网页或处理不可信文件时，在专用沙箱中运行，不与生产控制面或敏感数据平面共享权限。

### 隔离要求

- 以短生命周期、无状态的工作单元执行任务；任务结束即销毁运行环境。
- 禁止默认网络访问，仅允许到明确批准的目标；限制 DNS、代理和元数据服务访问。
- 使用非特权身份运行，限制文件系统挂载、进程创建、系统调用、CPU、内存、磁盘和执行时间。
- 输入文件进行类型和大小校验，在隔离区落盘；输出经扫描和内容校验后再返回。
- 密钥通过短期、范围受限的凭证按需注入，日志中不得记录凭证或原始敏感内容。

### 安全网关

在模型与沙箱之间增加策略执行点：根据用户身份、任务类型、风险等级和工具定义审批每一次操作。网关记录允许、拒绝、超时、资源消耗和策略版本，以便审计和复盘。

## 事件响应

1. 发现异常工具调用、可疑输出或沙箱逃逸迹象后，先停止受影响工具或会话。
2. 保全脱敏的请求、决策、工具参数和审计日志，评估影响范围。
3. 撤销或缩小相关凭证、权限和网络出口，修复策略或隔离缺口。
4. 回归测试提示注入、越权、资源耗尽和数据泄露场景，再逐步恢复服务。

## 上线检查

- 工具是否全部采用服务端授权与参数校验。
- 租户、用户和文档权限是否贯穿检索、缓存、工具与日志。
- 沙箱是否禁用默认网络与特权能力，并设置资源上限。
- 安全策略、审批和审计日志是否支持追溯与快速回滚。
