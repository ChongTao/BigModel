# Agent Memory 开源方案索引

本目录收录面向 Agent 记忆的开源实现。它们解决的问题不同，不能仅以“是否支持向量检索”判断能力边界。

| 方案 | 核心定位 | 适用场景 |
| --- | --- | --- |
| [Memobase](./2%20Memobase/1%20Memobase安装、使用与记忆管理.md) | 用户档案与事件记忆 | 个性化助手、用户运营 |
| [Mem0](./3%20Mem0/1%20Mem0安装、使用与记忆管理.md) | 通用记忆管理层 | 可维护的长期记忆 |
| [MemGPT / Letta](./4%20MemGPT.md) | 记忆感知运行时 | 长任务与上下文调度 |
| [Graphiti](./5%20Graphiti.md) | 时序图记忆引擎 | 动态关系与时间事实 |
| [LangMem](./6%20LangMem.md) | Memory tools 与 workflow | LangGraph 生态集成 |
| [Neo4j Agent Memory](./7%20Neo4j%20Agent%20Memory.md) | 图原生记忆服务 | 图谱、对话与推理痕迹 |
| [AgentMemory](./8%20AgentMemory/1%20安装、使用与记忆管理.md) | 面向 Agent 的记忆项目 | 记忆持久化、检索与维护 |

横向差异见[记忆方案对比](../3%20记忆方案对比.md)；选择与验证方法见[实践与评测](../20%20实践与评测/1%20选型指南.md)。
